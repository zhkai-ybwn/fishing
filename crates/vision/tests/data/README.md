# Face detection fixture

`portrait.rgb` contains a 160 × 160 crop of Commodore Grace M. Hopper's official portrait in packed RGB8 format. The source image is Matplotlib's `grace_hopper.jpg` sample. The U.S. Navy photograph by James S. Davis is in the public domain in the United States. [Portrait and credit](https://commons.wikimedia.org/wiki/File:Grace_Hopper.jpg)
